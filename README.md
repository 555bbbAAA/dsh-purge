基于上游 1.1.71 维护的 dsh-purge 社区兼容包：只负责 DeepSeek Harness 的版本兼容与本地 Windows 运行问题。

## 兼容范围

当前版本 **1.3.2**，声明 `dshTarget: >=0.2.1-rc.3 <0.3.0`。

| 宿主版本 | 状态 |
|---|---|
| 0.2.1-rc.3 | 完整支持，76 条补丁中 70 条可落、6 条 na |
| 0.2.1-rc.4 | 与 rc.3 同源，锚点未变 |
| 0.2.1-rc.5 | 已逐条核查：49 个补丁目标文件上游一个没改，桌面外壳五条注入结果与 rc.3 逐字节一致 |

上游 `YuJunZhiXue/dsh-purge` 声明只支持到 0.2.1-rc.2，本包在其基础上补齐了 rc.3 及之后的兼容。

## 这个包做什么

- 官方更新清空 `resources\runtime` 时自愈（preflight 插件 + Startup 守卫）
- 把上游的身份段与拒答面清洗掉
- 补丁换包、三态相位（active / dormant / needs-reapply）与状态可查
- 识别官方安装窗口：连官方更新器不写我们标记的场景（pending 里有不同版本的安装包）也能判出来，此时不写盘、不换包、不杀进程
